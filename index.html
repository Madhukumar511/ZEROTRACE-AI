03 — ENERGY OPTIMIZATIONS

4 Real Techniques — Each Measured Before & After

⚠ Benchmark the model first to enable these controls.
Token Limit
60–80% energy reduction
Sets num_predict — stops generation at N tokens. Energy saved is proportional to tokens NOT generated.
Awaiting benchmark…
Context Reduction
Attention is O(n²) — huge VRAM drop
Shrinks num_ctx (KV cache). 4096→512 = 64× less attention compute. GPU memory visibly drops in NVML.
Awaiting benchmark…
GPU Routing
Layer offload control
Controls GPU vs CPU layer distribution. GPU-lean = fastest inference, least wall-time energy. CPU-lean = lower peak wattage.
Awaiting benchmark…
Quant Switch
~50% less memory bandwidth
Switch to a lower-bit GGUF variant (Q8→Q4). Must ollama pull the variant first. Biggest long-term saving.
